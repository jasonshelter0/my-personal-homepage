# 简介头像

后台「媒体库」上传个人照片，填写中英法替代文字；在「个人资料 → 头像」中选择该图片，保存草稿、预览后发布。选择「无」再发布即可隐藏头像，页面不会保留空框或额外占位。

头像位于简介区姓名上方，三种语言及使用共享简介栏的页面一致。桌面外框128×128px，手机104×104px；图片居中以 `object-fit: cover` 方形裁切，建议上传至少512×512px、面部居中的照片。长方形原图不会被拉伸，但边缘可能被裁去。

边框和柔和边缘高亮跟随网站主配色，小圆角保留方形轮廓。无旋转、缩放或持续动画；减少动态效果设置下关闭边框过渡。较矮桌面窗口的简介栏随页面滚动，避免头像增加高度后遮住下方导航。

现有 `settings.avatarId` 和媒体库承担存储与发布，无新环境变量、依赖或数据库迁移。预览及正式版本使用发布器已有的媒体冻结机制；上传或保存草稿不会直接改变正式页面。

布局：`apps/site/src/layouts/Layout.astro`；样式：`apps/site/src/styles/global.css` 中 `.profile-portrait`；回归测试：`tests/browser/profile-portrait.spec.ts`。基于真实照片生成网站头像的提示词另见 `PORTRAIT_PROMPT.md`。
