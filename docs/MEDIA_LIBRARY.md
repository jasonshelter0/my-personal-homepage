# 媒体库组织与检索

媒体文件仍使用原有稳定ID和`/media/<filename>`路径。本功能只在草稿快照中增加可选的组织元数据，不移动、重命名、重新编码或重新上传已有资源。

## 使用方式

- **集合 / 分类**：每个资源可填写一个简短集合名，例如“文章配图”“项目”“个人照片”。已有集合会出现在筛选器和输入建议中；留空即“未分类”。
- **标签**：每项最多20个，以逗号分隔，例如“研究, 首页, 2026”。标签用于检索，不显示在公开网页。
- **搜索**：同时检索文件名、集合、标签，以及中英法三种语言的替代文字和题注。
- **引用筛选**：可查看全部、已引用或未引用资源。引用范围包含头像、封面、个人简介、首页分区和所有内容正文，包括草稿引用。
- **分页**：媒体库和正文插图选择器每页最多24项，避免资源增加后页面过长。插图选择器也可以按集合和全文搜索缩小范围。

修改集合、标签、替代文字或图注后需要保存草稿。它们不会改变现有文章中的图片引用；发布时仍只冻结实际使用的媒体文件。

## 兼容与删除

`Media.collection`、`Media.tags`和`Media.uploadedAt`均为可选字段。旧快照和生产资源不需要迁移：缺少分类的资源显示为“未分类”，缺少上传时间的资源按文件名稳定排序。新上传资源自动记录上传时间。

删除规则不变：仍被头像、封面、简介、分区或正文引用的资源无法删除。媒体分类不会影响引用检测，也不会删除历史发布版本中的冻结副本。

版本历史的删除是另一项操作：后台“预览与发布”可删除非当前、非构建中的版本，包括旧的已发布版本；它只删除所选版本的冻结目录和记录，保留草稿及媒体库原文件。
