# 首页分区、翻译与版本管理（1.3.0）

## 首页分区

在后台「外观与导航 → 首页分区」操作。首页导航、分区标题与后台导航不再显示装饰性的01/02序号；实际统计数量、文章日期与课程教学编号保留。

- 新建：点击「新建分区」，分别填写中英法标题。正文支持Markdown，若填写正文，三种语言都需完整；也可只选择已有内容卡片。
- 卡片：可选择文章、项目、信息页、经历，并单独排序。只有标记为「加入发布」的内容会显示；选中草稿不会将其公开。
- 管理：分区可改名、排序、隐藏或删除。删除分区不删除条目；原有关于/经历/项目/文章分区移除后可重新添加。每页最多30分区，每区最多100卡片。
- 发布：保存只改草稿。创建预览并检查后再发布，主页、导航、各语言和搜索索引一起更新。隐藏的未完成分区不会阻止发布。

原有分区继续从个人资料或相应内容类型自动取内容。自定义分区的标题、正文与选定卡片独立管理。分区中的本地图片通过现有媒体库上传、复制路径后插入Markdown；图片随版本冻结，隐藏分区引用的图片仍受媒体删除保护。

## 图片和分区翻译

媒体库可翻译图片替代文字与题注；分区编辑器可翻译标题与正文。选择源语言、当前目标语言及翻译服务，确认发送与覆盖后翻译。图片文件本身不发送给翻译供应商，仅发送文字。空题注/空正文保持为空。

默认MyMemory免密钥，沿用现有额度与请求限制；可选已配置的LibreTranslate/OpenAI兼容服务。翻译前保存编辑，失败或并发版本冲突不会写入部分译文。翻译结果需人工校对，再预览和发布。卡片条目自身的正文仍在「内容」中翻译。

## 删除发布记录

「预览与发布」的每条记录有删除按钮。可删除未发布预览、失败构建和历史发布版本；当前线上版本、构建中的版本禁止删除。删除当前版本前必须先发布或恢复另一个版本。

确认删除后会移除该版本的冻结页面、图片副本及构建日志，因此无法继续预览或回滚到它。草稿、媒体库原文件、其他版本不受影响。系统不会自动清理旧版本；本次部署也没有代用户删除已有历史。

## 设计致谢

公开页面已移除底部口号和演示站点声明，不展示Folio品牌。页脚仅提供「设计致谢」入口：`/zh-cn/site-notes/`、`/en/site-notes/`、`/fr/site-notes/`。同一逻辑页面的三种语言注明设计参考作者Brittany Chiang并链接原站；其他页面不重复作者引用。用户自有简介、文章及履历内容不会被批量改写。

## 给维护者

- 分区类型：`HomeSection`，旧 `{id, enabled}` 记录仍可读取；新增可选 `titles`、`body`、`entryIds`。自定义ID以 `section-` 开头，用作稳定锚点。
- SQL表结构与环境变量不变，无启动时内容迁移。发布验证检查三语文本、卡片引用、图片替代文字；前台只渲染启用分区及已发布卡片。
- `/api/translate` 新增互斥 `mediaId` / `sectionId` 目标、可选 `sourceLocale`；响应为更新后的Snapshot。
- `DELETE /api/releases/:id` 需要现有登录和同源校验，返回 `{releases, currentId}`。后端拒绝当前/构建中版本、非法路径与符号链接。
- 回滚优先使用保留的内容版本，运行时继续保留1.3.0。**使用新分区字段后，1.2.x不能解析新的草稿结构，不能直接降级应用镜像。** 若确需应用降级，先完成兼容性处理并验证，不要用旧数据库备份覆盖新草稿。部署时的旧镜像/内容/一致性备份记录在RELEASE_HANDOFF.md。
